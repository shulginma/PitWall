# PitWall 0.4.0: графический симулятор

Добавлены окно, трасса и машина с видом сверху, скорость, педали, контрольные точки,
текущий/лучший круг и история результатов. Физика работает шагами по 10 мс.
Каждый шаг передаётся модулю кругов.

## Запуск из терминала VS Code

```powershell
$env:Path = 'C:\msys64\ucrt64\bin;' + $env:Path
cmake --preset windows-mingw-gui
cmake --build --preset windows-mingw-gui --parallel 2
ctest --preset windows-mingw-gui
.\build\windows-mingw-gui\apps\simulator\pitwall_simulator.exe --drive
```

Выполняй команды из корня PitWall. Для окна нужен пресет windows-mingw-gui.
Старый windows-mingw собирает консольную версию. Запуск без --drive выводит статус.

| Клавиша | Действие |
| --- | --- |
| W | Газ |
| S | Тормоз, заднего хода пока нет |
| A / D | Влево / вправо |
| P | Пауза / продолжение |
| R | Новый заезд |
| Escape | Закрыть окно |

Кнопки Pause/Resume и Restart дублируют клавиши. Потеря фокуса или сворачивание
ставит заезд на паузу; после возвращения нажми P. Едь против часовой стрелки.
Начни с коротких нажатий газа и руля. Для зачёта нужны три контрольные точки.
При выезде круг станет недействительным, но движение продолжится. R вернёт на старт.

## F5 в VS Code

Установи расширение C/C++, выбери PitWall: Drive (MinGW) и нажми F5. Файлы
.vscode/tasks.json и launch.json запускают сборку и затем GDB. Путь отладчика:
C:/msys64/ucrt64/bin/gdb.exe. Интерактивная сессия F5 ещё не проверена.

## Новые файлы

- driving_session.hpp/cpp: объединение физики и кругов, пауза и новый заезд.
- gui_win32.cpp: окно, события Windows, OpenGL и освобождение ресурсов.
- gui_view.cpp: интерфейс и отрисовка.
- FixedStepSimulation: стартовая/предыдущая позиция и все шаги кадра.
- tests/session_cases.hpp: 10 новых проверок.
- third_party/imgui: исходники Dear ImGui с исходной лицензией и хешами.

Сборка и 68 тестов прошли на MinGW и MSVC. На обоих компиляторах выполнена реальная
отрисовка диагностического кадра OpenGL. Клавиатура и ручной круг ещё требуют проверки
в окне. Архитектура и ограничения описаны в docs/gui.md.

Использован Win32 + OpenGL + ImGui: доступная старая GLFW-библиотека не связалась
с MinGW. Платформенный слой отделён от логики; Linux пока без графики. Скачивать
библиотеки не нужно. Нужен рабочий видеодрайвер с OpenGL 3.0 или новее.
